# Coding challenge: 242 Valid Anagram (Arrays and hashing)

Link: https://leetcode.com/problems/valid-anagram/

**Problem (my words):** You get two strings, `s` and `t`. Return `true` if `t` is made of exactly the same characters as `s`, each used the same number of times, just in a different order. Otherwise `false`.

Example: `s = "listen"`, `t = "silent"` → `true`. `s = "rat"`, `t = "car"` → `false`.

Constraints that matter: lowercase English letters only, length up to about 50,000. Think about what changes if the strings could contain any Unicode characters (follow-up, be ready to discuss it).

**Language:** Java. Target: 30–40 min. Before coding, write your approach and its time/space complexity in a comment.

## Hints
1. If the lengths differ, you can answer immediately. Otherwise, what do two anagrams have in common character by character?
2. Count how often each character appears. You don't need to sort.
3. One count structure can do both strings: add for `s`, subtract for `t`, then check that nothing is left over. For lowercase-only input a fixed-size array is enough; for Unicode, what would you use instead?

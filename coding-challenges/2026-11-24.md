# Coding challenge: Group Anagrams (LeetCode 49, Java)

Link: https://leetcode.com/problems/group-anagrams/

**Problem (my words):** You get an array of lowercase strings. Put the words that are anagrams of each other (same letters, any order) into the same group, and return all the groups. Group order and order inside a group don't matter.

Example: `["eat","tea","tan","ate","nat","bat"]` → `[["eat","tea","ate"],["tan","nat"],["bat"]]`

Constraints that matter: up to about 10^4 words, each up to about 100 characters, lowercase a-z only.

Target: 30–40 min. Before coding, write your approach and its time/space complexity in a comment.

## Hints
1. Two words are anagrams if they share some "canonical form". What could you compute per word that is identical for all its anagrams?
2. Use that canonical form as a `HashMap` key, with a `List<String>` as the value. `computeIfAbsent` is handy.
3. There are two common keys: the sorted characters (cost per word O(k log k)) or a 26-count array turned into a string (O(k)). Be ready to state when the second beats the first, and why an `int[]` can't be used directly as a map key.

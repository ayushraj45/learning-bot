# Coding challenge: Longest login streak (SQL)

## Problem

You have a table `logins` recording which days each user logged in. Find, for each user, their **longest streak of consecutive days** logged in, and the start and end date of that streak.

```
logins(user_id INT, login_date DATE)
```

A user can have multiple rows for the same day (duplicates). Count a day only once.

## Example

Input:

| user_id | login_date |
|---------|------------|
| 1 | 2026-03-01 |
| 1 | 2026-03-02 |
| 1 | 2026-03-02 |
| 1 | 2026-03-03 |
| 1 | 2026-03-07 |
| 2 | 2026-03-05 |
| 2 | 2026-03-09 |
| 2 | 2026-03-10 |

Output:

| user_id | streak_days | streak_start | streak_end |
|---------|-------------|--------------|------------|
| 1 | 3 | 2026-03-01 | 2026-03-03 |
| 2 | 2 | 2026-03-09 | 2026-03-10 |

## Constraints

- Postgres-style SQL. Table can have tens of millions of rows, so avoid self-joins on the full table.
- If a user has two streaks of the same max length, return the earliest one.
- One row per user.

## Hints

<details>
<summary>Hint 1</summary>
Dedupe first: one row per user per day.
</details>
<details>
<summary>Hint 2</summary>
Number each user's days with ROW_NUMBER ordered by date. For consecutive days, what happens when you subtract that row number (as days) from the date?
</details>
<details>
<summary>Hint 3</summary>
That difference is constant within a streak, so GROUP BY user and that value gives you the "islands". Then pick the top island per user.
</details>

# Coding challenge: Two Sum (Arrays and hashing)

LeetCode #1 Two Sum: https://leetcode.com/problems/two-sum/

**Problem (my words):** You get an int array and a target number. Find the two *different positions* whose values add up to the target and return those two indices. Exactly one valid pair exists, and you can't use the same element twice. Order of the returned indices doesn't matter.

Example: `nums = [3, 8, 5, 2]`, `target = 10` → `[1, 3]` (8 + 2).
Example with duplicates: `nums = [4, 4, 9]`, `target = 8` → `[0, 1]`.

Constraints that matter: array length up to about 10^4, values can be negative, exactly one answer.

**Target: 30–40 min.** Before coding, write your approach and its time/space complexity in a comment. Use Java (`HashMap<Integer,Integer>` is the natural tool).

## Hints
1. The brute force checks every pair. What single question could you ask about each number to avoid the second loop?
2. For the current number x, you need `target - x`. Where could you have stored numbers you've already seen so lookup is instant?
3. Store value → index as you go, and check for the complement *before* inserting the current number. Think about why that order handles the duplicate case.

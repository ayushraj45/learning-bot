# NeetCode 150 · Arrays and hashing · #1

**LeetCode 217. Contains Duplicate**
https://leetcode.com/problems/contains-duplicate/

## Problem (my words)
You get a list of integers. Return `True` if any value shows up more than once, otherwise `False`.

Example: `[4, 7, 1, 4]` → `True` (4 repeats). `[3, 8, 5]` → `False`.

Constraints that matter: the list can have up to around 100,000 numbers, values can be negative, and it can have a single element (answer is `False`).

Target: 30–40 min. Before coding, write your approach and its time/space complexity in a comment.

Python only. Also be ready to say what you'd do if memory were very tight.

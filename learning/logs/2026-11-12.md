### Lesson 21 [data, lesson]: Deduplicating rows in SQL
**Ayush** (2026-11-12 15:01): Wait why can J not use select distinct for email instead? I’ll only get one email yeah? And can you show an example of adding another ID to the sort part?
**Tutor** (2026-11-12 15:01): Yes—`SELECT DISTINCT email` gives you one row per email, but only returns the email. It doesn’t tell SQL which customer row to keep if you also need the name, `updated_at`, or other columns. `SELECT DISTINCT *` won’t collapse rows when those other columns differ.

For example, if two rows have the same `email` and `updated_at`, add a unique `id` as a tie-breaker:

```sql
ROW_NUMBER() OVER (
  PARTITION BY email
  ORDER BY updated_at DESC, id DESC
) AS rn
```

This picks the newest row; if timestamps tie, it picks the row with the higher `id`. The tie-breaker makes the choice predictable.
